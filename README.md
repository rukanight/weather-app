# Weather App

都市名を入力すると、現在の天気と簡単な今日の予報を表示するPythonアプリです。

## 機能

- 都市名から緯度・経度を取得
- 現在の気温を表示
- 現在の湿度を表示
- 現在の天気を表示
- 現在の風速を表示
- 9時と15時の天気をもとに簡単な今日の予報を表示
- 都市が見つからない場合は再入力

## 使用技術

- Python
- Open-Meteo API
- requests
- Git
- GitHub

## 実行方法

### 1. 仮想環境を有効化

```bash
source .venv/bin/activate
```

### 2. 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

### 3. アプリを実行

```bash
python main.py
```

## 仕組み

1. 入力された都市名をOpen-MeteoのGeocoding APIに送信
2. 都市の緯度・経度を取得
3. 緯度・経度を使って天気APIにアクセス
4. 現在の気温・湿度・天気コード・風速を取得
5. 天気コードを日本語の天気に変換
6. 9時と15時の天気から簡単な今日の予報を作成
7. 結果をターミナルに表示
